# AWS Control Validation Screenshots

This folder contains sanitized screenshots showing selected security, identity, monitoring, and auditing controls configured or reviewed in the AWS Academy environment.

The screenshots provide evidence of hands-on validation for selected parts of the proposed architecture. Some account-level controls and production components remained design-specified because the AWS Academy lab role restricted the required permissions.

## Included Evidence

- AWS CloudTrail management-event activity
- Amazon CloudWatch alarm demonstration
- AWS IAM password-policy demonstration
- Database-tier security-group rule validation

All unnecessary account, user, and resource identifiers have been removed or obscured before publication.
